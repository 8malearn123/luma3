# دليل تصميم واجهات لوما

هذا الدليل يُطبَّق على **أي شاشة أو مكوّن داخلي** يُضاف أو يُعدَّل في لوما 3. وكل وكيل برمجي يعمل في المشروع يقرؤه قبل لمس الواجهات، لأن `AGENTS.md` يشير إليه.

**الأصل:** نقلنا **تجربة الاستخدام والانضباط البصري** من استراتيجية «ڤيوليت هايلايت». أما **هوية لوما فثابتة لا تتغير**: ألوانها وشعارها وخطوطها.

> ما لا يُنقل من هايلايت: ألوانها (البنفسجي والليموني)، وخطوطها (Baloo وReadex)، وشخصية «ڤيو»، وبنية CSS العادي. لوما تبقى على Tailwind v4 وTokens لوما.

## القرارات (2026-11-15)

| الموضوع | القرار |
|---|---|
| النطاق | نقل التجربة والانضباط البصري **دون تغيير هوية لوما** |
| التوقيت | يبدأ **بعد الانتهاء من مساري المخزون والاستضافة** |

| نطاق المرور التصميمي | **كل اللوحات الداخلية**: النشاط، والفريلانسر، والمنصة، وحساب العميلة. لا يشمل المتجر العام والموقع التسويقي |

## 1. المبدأ العام

- **«نُبرز المهم، والباقي هادئ»**: الواجهة نظيفة، والإبراز محجوز لشيء واحد مهم في كل شاشة.
- **عربي أولًا**: الصفحة `dir="rtl"`. استخدم الخصائص المنطقية في Tailwind:
  - `ms-* / me-* / ps-* / pe-* / start-* / end-* / text-start`
  - لا تستخدم `ml/mr/pl/pr/left/right`.
- **لا نمط جديد قبل البحث عن نمط قائم.** استخدم أولًا مكوّنات `src/ui/components/*`:
  - `Button` و`IconButton`
  - `Card` و`PageHeader` و`Tabs` و`DataTable` و`Pager` و`Stat`
  - `Field` و`Input` و`Select` و`Textarea` و`Checkbox` و`Switch` و`MoneyInput` و`LocalizedInput` و`FormErrorSummary`
  - `Alert` و`Badge` و`EmptyState` و`LoadingState` و`ErrorState` و`DeniedState` و`Spinner`
  - `Dialog` و`Drawer` و`ConfirmDialog`
  - `useToast`

## 2. Tokens: مصدر الحقيقة الوحيد

المصدر هو `src/app/globals.css` داخل `@theme`، وفيه طبقتان:

| الطبقة | المحتوى | الاستخدام |
|---|---|---|
| **هوية لوما** (لا تُعدَّل قيمها) | `luma-50…900`، و`font-sans` (IBM Plex Sans Arabic)، و`font-display` | الأسطح والعناصر الأساسية في لوحات لوما فقط |
| **دلالية** | `ink`، `ink-muted`، `line`، `ok/ok-bg`، `warn/warn-bg`، `danger/danger-bg`، `info/info-bg` | النصوص والحدود والحالات |
| **المتجر** `sf-*` | ثيم كل نشاط | المتجر العام فقط؛ لا تستخدمه في اللوحات |

### قواعد إلزامية

- **ممنوع** كتابة أي لون hex أو `rgb()` أو ظل أو مدة حركة يدويًا داخل المكوّنات أو `style={{…}}`. استخدم كلاسات Tailwind المبنية على الـ Tokens (`bg-luma-50`، `text-ink-muted`، `border-line`…).
- إذا احتجت قيمة غير موجودة، **أضفها Token دلاليًا** في `@theme` مع **مقابلها الداكن**، ثم استخدمها.
- **الوضع الداكن مُعتمد**، فكل Token دلالي جديد يجب أن تكون له قيمة داكنة. أي لون مكتوب يدويًا سيكسر الوضع الداكن.
- **المسافات** على شبكة 4px بمقياس Tailwind (`gap-1`=4px…).
- **الزوايا**:

  | العنصر | الكلاس |
  |---|---|
  | البطاقات | `rounded-2xl` |
  | الأزرار | `rounded-xl` |
  | الحقول | `rounded-lg` |
  | النوافذ | `rounded-3xl` |

  ثبّت الاختيار بعد مراجعة المكوّنات الحالية ووحّده فيها.
- **الظلال** خفيفة ومبنية على لون الحبر. الظل الملوّن للزر الأساسي فقط.

## 3. الألوان: متى يُستخدم كل لون

| اللون | متى |
|---|---|
| `luma-500 / luma-700` | الزر الأساسي، والروابط، ومؤشر العنصر النشط، والأيقونات النشطة |
| `luma-800 / luma-900` | العناوين والعنصر النشط في القائمة |
| `luma-100 / luma-200` | ضربة التظليل، وخلفية عنصر القائمة النشط، والأزرار الناعمة عند التمرير |
| ألوان الحالات `ok / warn / danger / info` | مستقلة عن الهوية. التباين AA مطلوب. لا تُستبدل بألوان لوما |

- الخلفية `bg-luma-50`، والأسطح بيضاء، والحدود `border-line`.
- **بطاقة مؤشر بلون حالة**: أيقونة على `*-bg` بلون الحالة، والرقم بلون الحالة. استخدم `Stat` ووسّعه بدل بطاقة جديدة.

## 4. الطباعة

- **الخط الأساسي** `font-sans` (IBM Plex Sans Arabic) للنصوص والأرقام والجداول والحقول والأزرار والشارات. هذه **هوية لوما ولا تتغير**.
- **العناوين** (عنوان الصفحة، وعناوين الأقسام والنوافذ، وعناوين الحالات الفارغة): وزن عريض بنفس الخط. `font-display` (Cinzel) للعلامة اللاتينية فقط.
- **المقياس** متجاوب: عنوان الصفحة بـ `clamp()`، والنص 15px، و`leading-snug` للعناوين، و`leading-relaxed` للنص.
- **تباعد الحروف 0 للعربي دائمًا**: لا `tracking-*` على النصوص العربية.

## 5. عناصر التجربة المنقولة

### ضربة التظليل `<Highlight>`
المكوّن يُضاف في `src/ui/components/brand.tsx`.

- **ضربة واحدة فقط في كل شاشة**، خلف الكلمة الأهم في العنوان الرئيسي.
- **الدرجات**: `soft` (افتراضي، `luma-200`)، و`strong` للإنجاز والأولوية العالية، و`onBrand` فوق خلفية لوما الداكنة.
- **ممنوعة** داخل الجداول والحقول والشارات والنصوص التشغيلية.
- لإبراز عنصر ثانٍ في الشاشة استخدم حلقة `ring-luma-200` أو شارة، لا ضربة ثانية.
- تُرسم بحركة قصيرة، مع بديل ثابت تحت `prefers-reduced-motion`.

### المرشد بدون شخصية
نفس **نمط** الإرشاد، لكن برسم أيقوني بهوية لوما: `lucide-react` داخل شكل `luma-100`، أو `LumaMark`. لا توجد شخصية مرسومة.

| يظهر في | لا يظهر في |
|---|---|
| الترحيب | نتائج بحث أو تصفية فارغة: `EmptyState` بلا رسم |
| الحالة الفارغة **الأولى** (لا توجد بيانات بعد) | |
| الإنجاز (مثل إغلاق شهر أو اعتماد) | |
| تنبيه أولوية عالية متأخر | |
| مركز المساعدة | |

- لا يتكرر في الشاشة الواحدة.
- **لا تكتب «AI» أو «المساعد الذكي»** في رسائل الإرشاد. الإرشاد قواعد محددة. وحدة «لووم» لها تسميتها الخاصة.

### نقطة العنصر النشط
نقطة `luma-500` صغيرة مؤشرًا للعنصر النشط في القائمة الجانبية.

## 6. هيكل الشاشة الداخلية

- **الإطار القائم** في `src/ui/shell/*`: القائمة الجانبية، والشريط العلوي، والمحتوى. أي صفحة جديدة تُسجَّل في `src/ui/shell/nav.ts` بقدراتها (`caps`) وميزة الباقة (`feature`) ونوع النشاط (`hideFor` / `workspace-profile`).
- **الترتيب المعتاد للصفحة**:
  1. `PageHeader`، وفيه ضربة التظليل في العنوان.
  2. صف مؤشرات (`Stat`).
  3. شريط أدوات: بحث، ثم فلاتر، ثم زر أساسي واحد.
  4. المحتوى: جدول `DataTable`، أو شبكة بطاقات، أو تبويبات `Tabs`.
  5. التفاصيل في `Drawer` أو `Dialog`.
- **زر أساسي واحد لكل منطقة**، والبقية `outline` أو `ghost`.
- **احترم الصلاحيات في العرض**: أخفِ أو عطّل الإجراءات حسب `access.can(...)` و`access.readOnly`. الخادم هو الحكم النهائي.
- **حالات إلزامية** لكل قائمة أو بيانات: تحميل (`LoadingState`)، وخطأ مع إعادة المحاولة (`ErrorState`)، وفراغ (`EmptyState`)، ومنع (`DeniedState`).

## 7. الحركة

- **قصيرة وناعمة**: 120ms للتفاعل، و200ms للظهور، و420ms لرسم الضربة، ومنحنى ease-out. CSS فقط، بلا مكتبات حركة.
- **المسموح**: ظهور أو صعود، وطفو خفيف، وقفزة احتفال عند الإنجاز، وهزة تنبيه، ورسم ضربة التظليل.
- **إلزامي**: لكل حركة بديل تحت `motion-reduce:` / `@media (prefers-reduced-motion: reduce)` يُظهر الحالة النهائية ثابتة.

## 8. الوصول والجودة (WCAG AA)

- **تباين** ≥ 4.5:1 للنص، في الوضعين الفاتح والداكن.
- **تركيز مرئي دائمًا**: `:focus-visible` موجود في `globals.css`. لا تحذف الـ outline.
- **عناصر تفاعلية حقيقية** (`button` و`a`).
- `aria-label` (عبر `IconButton label`) للأزرار الأيقونية.
- `role="status"` و`aria-live` للتحميل والتنبيهات.
- الرسوم الزخرفية `aria-hidden`.
- **منع التمرير الأفقي**: عناصر flex/grid تأخذ `min-w-0`، والجداول داخل حاوية تمرير. اختبر على عرض 375px.

## 9. التجاوب

- نقاط Tailwind: `sm 640`، و`md 768`، و`lg 1024`، و`xl 1280`.
- الشبكات `grid-cols-[repeat(auto-fill,minmax(…,1fr))]` أو أعمدة متدرجة.
- اختبر على **375px و1440px**.

## 10. النبرة والمحتوى

- **رسائل الإرشاد والحالات الفارغة**: لهجة سعودية/خليجية ودودة ومختصرة، مثل «كل شيء هادي! أضيفي أول خدمة ونبدأ.».
- **التسميات والحقول**: فصحى واضحة.
- **النصوص من ملفات i18n** (`src/i18n/messages/*`)، بمفاتيح متطابقة بين ar وen. لا نصوص مكتوبة داخل المكوّنات.
- **الأرقام والعملة والتواريخ** من `useFmt()`: `money` و`when`.
- **لا أرقام أداء أو شهادات** غير موثّقة.

## 11. الوضع الداكن

- **التفعيل**:
  - `:root[data-theme="dark"]` يعيد تعريف الـ Tokens الدلالية.
  - زر تبديل في قائمة المستخدم يحفظ الاختيار.
  - الافتراضي يتبع `prefers-color-scheme`.
- **نطاقه**: اللوحات الداخلية فقط. المتجر العام له ثيمه `sf-*`.
- **ترتيب التنفيذ**: قبل تفعيله لكل المستخدمين يجب **تحويل الألوان المكتوبة يدويًا في اللوحات إلى Tokens**. هذا أول خطوة في المرور التصميمي.

## 12. قائمة تحقق قبل التسليم

- [ ] RTL سليم بالخصائص المنطقية.
- [ ] حالات التحميل والخطأ والفراغ والمنع موجودة بالمكوّنات الموحّدة.
- [ ] تركيز مرئي، وتباين AA في الوضعين، و`prefers-reduced-motion` محترم.
- [ ] تجاوب بلا تمرير أفقي من 375px.
- [ ] الصلاحيات وميزات الباقة محترمة في الأزرار والأقسام.
