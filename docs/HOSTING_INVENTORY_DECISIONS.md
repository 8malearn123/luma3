# المستودعات والتكاليف واستضافة الفريلانسر — القرارات وحالة المتطلبات

النطاق: (1) مستودعات متعددة المواقع وحركة المواد حتى استهلاكها، (2) ربط المخزون بالمحاسبة والتكاليف والفواتير، (3) حجز الفريلانسر المشتركة في لوما لكرسي أو مساحة عمل لدى صالون مشترك.

هذا الملف هو المرجع الملزم. أي خيار غير مذكور هنا لا يُنفَّذ دون قرار.

## 1. القرارات المعتمدة (2026-11-10)

| # | الموضوع | القرار | أثره على التنفيذ |
|---|---|---|---|
| D1 | طريقة حجز المساحة | **يختارها الصالون لكل إعلان: فوري أو بعد موافقته** (بعض الصالونات تريد اختيار من تستضيف). | `booking_mode = instant \| approval` في الإعلان. |
| D1b | التوفر | الكرسي يُربط بموظفة أو أكثر؛ يكون مشغولًا وقت حجوزاتهن، والكرسي غير المرتبط بموظفة متاح ضمن ساعات العمل. **النشر للإيجار اختياري** لكل مساحة وأوقاتها (المتطلب 9). | جدول ربط الكرسي بالموظفات، ومصدر تخصيص موحد `booking_allocations`. |
| D1c | مهلة الرد في الحجز بالموافقة | **ساعتان ثابتتان** (ولا تتجاوز بداية الحجز)، ثم ينتهي الطلب ويتحرر الكرسي. | حجز مؤقت `held` بانتهاء. |
| D2 | تسعير الإطلاق | **سعر ثابت فقط** (بالساعة أو الفترة أو اليوم). البنية تدعم النسبة لكنها **معطلة** ولا تظهر. | `price_model` + أعمدة النسبة وأساسها محفوظة وغير مفعلة. |
| D3 | تحصيل قيمة خدمة العميلة | **الفريلانسر تحصّل من عميلتها** مباشرة. لا تقسيم دفع. | خدمة العميلة إيراد للفريلانسر فقط. |
| D3b | دفع الإيجار والإضافات | **إلكترونيًا للصالون** عبر حساب الدفع المربوط بالصالون في لوما (الصالون هو التاجر). | دفع ضمن مزود الصالون؛ لا تحويلات بين الأطراف. |
| D3c | صالون بلا مزود دفع | **الصالون يربط مزوده من خلال لوما**؛ النشر يتطلب حساب دفع مفعّل (المزود التجريبي مقبول في النسخة التجريبية). | شرط نشر الإعلان. |
| D4 | المناقلة الداخلية | **إعداد لكل منشأة**: الافتراضي فوري، ويمكن تفعيل تأكيد الاستلام (الكمية «قيد النقل» لا تكون متاحة في الموقعين). | `transfer_confirmation` في إعدادات المخزون. |
| D5 | المواد المشمولة في الإيجار | **لا مواد مشمولة**. الفريلانسر تحضر موادها، وإن احتاجت شيئًا **تشتريه من متجر الصالون كقطعة كاملة**، أو **تستأجر معدات**. | الإضافات = بيع منتج كامل (بيع مباشر بحركة بيع) أو تأجير جهاز. لا تحميل جزئي للمواد. |
| D5b | سعر المنتج للفريلانسر | **سعر المتجر**، مع إمكانية أن يقدّم الصالون **خصمًا شاملًا** على الإضافات. | خصم نسبة على الإضافات في الإعلان، محفوظ في نسخة الشروط. |
| D6 | القوالب | **كرسي أساسي + إضافات تختارها الفريلانسر مع كل حجز** (لا قوالب). | الإعلان = سعر أساسي + قائمة إضافات. |
| D7 | الحجز المتكرر | **غير موافق** — حجز مفرد فقط. | — |
| D8 | الوصول والمغادرة | **موافق مع رسوم تأخير معلنة**؛ تسجيل برمز أو QR. الرسوم **مقترحة ويعتمدها الصالون** قبل دخولها التسوية. | بند رسوم مقترح بحالة `proposed`. |
| D9 | التقييمات | **الفريلانسر تقيّم المساحة** بعد حجز مكتمل. تقييم خدمة الفريلانسر من **العميلة** (النظام الحالي). الصالون لا يقيّم. | جدول تقييم مساحات منفصل. |
| D10 | إلغاء موعد العميلة | **حجز المساحة يبقى قائمًا**؛ إلغاؤه قرار مستقل بشروطه المحفوظة. | لا ربط آلي للإلغاء. |
| D11 | ربح لوما من الاستضافة | **بنية رسوم معطلة**: ضمن الاشتراك الآن، مع إعداد منصة لرسوم/عمولة قيمته صفر ومعطل. | `platform_fee` في التسوية = 0 ومعطل. |
| D12 | توزيع المميزات على الباقات | **موافق بمصفوفة مقترحة** موسومة «مقترح — غير معتمد» للمراجعة. | مفاتيح مميزات جديدة وتوزيع مبدئي قابل للتعديل من إدارة الباقات. |
| D13 | الفاتورة للفريلانسر | **تُصدر تلقائيًا** من نظام الفواتير الحالي عن الإيجار والإضافات (ضريبية إن كان الصالون مسجلًا). | فاتورة لكل حجز مساحة مدفوع/مكتمل. |
| D14 | خصوصية عميلات الفريلانسر | **الصالون لا يرى شيئًا** عن مواعيد عميلات الفريلانسر؛ يرى حجز المساحة فقط. | لا API للصالون على روابط المواعيد. |
| D15 | تقييم المخزون | **المتوسط المرجّح**؛ تكلفة كل حركة تُحفظ وقتها ولا تتغير بتعديل لاحق. | `avg_cost` للصنف + تكلفة على كل حركة. |

## 2. ما كان موجودًا وأُعيد استخدامه

| موجود | الاستخدام |
|---|---|
| `inventory_items`, `stock_movements` (append-only, exactly-once), `moveStock` | أصبح الصنف «بطاقة صنف» والأرصدة لكل موقع؛ الحركة تحمل الموقع والتكلفة. |
| `service_material_recipes`, استهلاك عند إكمال الحجز | الوصفة = الكمية المتوقعة؛ الاستهلاك الفعلي سجل مستقل يُرحَّل مرة واحدة. |
| `stock_counts` | الجرد لكل موقع مع اعتماد. |
| `resources`, `booking_allocations` + قيود الاستبعاد | الكرسي مورد قابل للحجز؛ حجز المساحة يحجز نفس المورد بنفس القيد (مصدر موحد). |
| `time_blocks` | الصيانة والحجب اليدوي للكرسي. |
| `financial_entries` + `post()` | ترحيل المخزون والمشتريات والاستضافة. |
| `invoices` + ZATCA | فاتورة الصالون للفريلانسر. |
| `payment_accounts` / مزود الدفع | دفع الإيجار للصالون. |
| `plans` / `plan_features` / `loadEntitlements` | مصفوفة المميزات. |
| أدوار وصلاحيات المستأجر | إضافة دور «مسؤول مستودع». |
| `tenants.business_type = 'expert'` | حساب الفريلانسر المستقل. |
| `loom_export` | بيانات الاستضافة والتكاليف للتحليل. |
